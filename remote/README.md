# Nova TV Remote

Приложение для Android: телефон работает как «лазерная указка» и пульт для Nova TV на компьютере.
Наклоняете телефон — курсор на экране двигается следом.

## Как это работает

- Телефон находит компьютер в сети Wi-Fi (рассылка по UDP) или вы вводите адрес вручную.
- Один раз вводится 6-значный код из Nova TV (**Настройки → Телефон-пульт**). После этого телефон запоминается,
  и дальше подключается сам. Код после каждого сопряжения меняется.
- Курсор: приложите палец к большой площадке и наклоняйте телефон (верхний край смотрит на экран). Пока палец лежит на площадке, курсор следует за наклоном; быстрое касание — клик. Отпустили палец — курсор стоит.
- Справа полоса прокрутки, внизу крестовина с OK и кнопки «Назад», «Домой», «Меню», «Адрес», а ещё клавиатура телефона для ввода текста.
- В «настройках указки» (значок ползунков) меняются скорость курсора и направления осей, если наклон кажется «зеркальным».

## Сборка

Нужны [Flutter SDK](https://docs.flutter.dev/get-started/install) и Android Studio (для Android SDK). Проверка: `flutter doctor`.

Из папки `remote/`:

```bash
flutter create --platforms=android --project-name=novatv_remote --org=com.novatv .
git checkout -- lib pubspec.yaml analysis_options.yaml
node tool/setup.js
flutter pub get
```

Первая команда создаёт папку `android/` (и может перезаписать `lib/main.dart` шаблоном, поэтому вторая команда возвращает наши файлы).
Скрипт `tool/setup.js` добавляет в манифест доступ в сеть и название приложения.

Запуск на подключённом по USB телефоне (включите «Отладку по USB»):

```bash
flutter run
```

Установочный файл (APK) для себя и друзей:

```bash
flutter build apk --release
```

Готовый файл: `build/app/outputs/flutter-apk/app-release.apk`. Его можно отправить на телефон и установить (разрешив установку из неизвестных источников).

## Если не подключается

- Телефон и компьютер должны быть в одной сети Wi-Fi (не гостевой: у гостевых часто запрещена связь между устройствами).
- В Nova TV включён переключатель «Управление с телефона».
- При первом включении Windows спрашивает про доступ к сети: разрешите для **частных сетей**. Если пропустили, разрешите в «Брандмауэр Windows → Разрешение взаимодействия с приложением» для Nova TV (или `electron.exe`, если запускаете из разработки).
- Если компьютер не находится в списке, нажмите «Ввести адрес вручную»: адрес показан в Nova TV под кодом (например, `192.168.1.10:47800`).
