# Nova TV

Nova TV — свой «Google TV» на Electron: главный экран с плитками, YouTube (TV-интерфейс), поиск фильмов и сериалов
с просмотром раздач прямо в приложении, управление геймпадом и клавиатурой.

## Что внутри

- **YouTube** — официальный TV-интерфейс (`youtube.com/tv`) в отдельном окне, вход в аккаунт сохраняется.
- **Фильмы и сериалы** — поиск, подборки, страницы фильмов, актёров, продолжение просмотра, пропуск заставки, следующая серия.
- **Просмотр торрентов без скачивания целиком** — WebTorrent + ffmpeg (оба внутри приложения).
- **Поиск раздач** — через Prowlarr. Он скачивается и запускается самим приложением, трекеры настраиваются в «Настройки → Источники раздач».
- **Геймпад** — стрелки, A/B/X/Y, бамперы.

## Скачать готовую версию

Откройте раздел **Releases** репозитория и скачайте файл для своей системы.

**Windows** (основная платформа, всё проверено):

- `NovaTV-Setup-….exe` — установщик;
- `NovaTV-Portable-….exe` — запускается без установки.

**macOS** (`NovaTV-…-mac-arm64.dmg` для Apple Silicon, `…-x64.dmg` для Intel) и **Linux** (`NovaTV-…-linux.AppImage`):
сборки появились недавно и **не проверялись на реальных машинах**. Приложение не подписано, поэтому на macOS первый запуск —
правый клик по приложению → «Открыть»; на Linux перед запуском: `chmod +x NovaTV-*.AppImage`.

## Первый запуск

1. **Настройки → Поиск и источники → Ключ поиска фильмов** — вставьте ключ с [poiskkino.dev](https://poiskkino.dev) (бесплатный).
2. **Настройки → Поиск и источники → Источники раздач** → «Скачать и установить Prowlarr» (около 130 МБ, один раз) →
   «Открыть каталог трекеров» и добавьте нужные (для русских озвучек: RuTor, NoNaMe Club, RuTracker и т. д.).
3. Выберите фильм и нажмите «Смотреть».

Уже есть свой Prowlarr? В «Источники раздач» выберите «Свой» и укажите адрес и ключ.
Два Prowlarr одновременно запустить нельзя (так устроен сам Prowlarr), поэтому закройте один из них.

Все настройки и ключи хранятся только у вас: `%APPDATA%\google-tv-win\settings.json`.

## Сборка из исходников

Нужны Node.js 20+ и Windows.

```bash
npm install
npm run dev      # разработка (окно приложения + горячая перезагрузка интерфейса)
npm run start    # собрать интерфейс и запустить без упаковки
npm run dist         # Windows: установщик и portable-версия в папке release/
npm run dist:mac     # macOS (собирать нужно на macOS)
npm run dist:linux   # Linux (собирать нужно на Linux)
```

Сборка на GitHub: отправьте тег вида `v0.1.0` (`git tag v0.1.0 && git push --tags`) — workflow
`.github/workflows/release.yml` соберёт версии для Windows, macOS и Linux и приложит их к релизу.

## Горячие клавиши

| Клавиша | Действие |
| --- | --- |
| F11 | окно / полный экран |
| F8 | звуки интерфейса вкл/выкл |
| Esc | назад |
| A / Ф | выбор звуковой дорожки в плеере |
| S / Ы | пропустить заставку |
| N / Т | следующая серия |
| M / Ь | ручной выбор раздачи для серии |
